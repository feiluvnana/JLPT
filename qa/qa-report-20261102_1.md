## 4. Findings

### F1 — 問題1-5 蒸し暑い: the printed medial okurigana selects the key (自動不合格; item replaced, key position 4 kept)

- **Section:** 文字・語彙. The redraw goes through `exam-blueprint`.
- **Evidence.** `言語知識・読解.md` L17 reads 「今日は朝から本当に**蒸し暑い**ですね。」, with options 「はださむい／なまぬるい／あつくるしい／むしあつい」. With the kanji covered, the span reads □し□い, and only むしあつい carries a し between two kanji readings. The item's own 解説 says 「四つとも下線の範囲と同じ尾「い」で終わる」. That holds for the tail only. The rule in this file is "cover the kanji, keep okurigana visible — if only one option still fits, fail it". This is the automatic-fail class "printed okurigana then selects the key on sight".
