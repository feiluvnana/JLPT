## 問題1
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 2 | 1 ✗「シンポジウムのポスター、掲示板に貼ってくれたんだね。ありがとう」→既に済んでいる／2 ○「当日のスタッフ用のスケジュール表、これないから欲しいな。今週中にお願いしていい?」→今週中に頼まれた仕事／3 ✗「発表者の方からの資料まだ全部集まってないんですよ」「集まり次第コピーしよう」→資料が集まってからで、今はできない／4 ✗「私から発表者に資料を送ってもらうようにすぐに連絡をする」→女の学生がする。 |
| 2番 | 1 | 女「先生の許可がない限りは、勝手に変えられないよ。まず、研究室に行ってみれば？」男「わかった」＝先生の研究室に行く。2 ✗ リーさんへの連絡は先生の許可後。3 ✗ 直接会えるためメールはやめた。4 ✗ 目の前にいる女の学生には後で連絡する。 |
| 3番 | 3 | 課長「今までのものと図で比較するとか、そういう感じの方がいいんじゃないかな」→女「はい、そうします」＝以前の商品と比べた図を入れる。文字の色は「あんまり目立たない」という指摘のみで直す指示はなく、数字は「大きく目立つように書いてある」で十分、変更点のまとめは「他に付け加えるものはないね」と評価済み。 |
| 4番 | 1 | 男「現金で、別々でお願いします。クーポンは1枚で3名まで」＝現金で別々に支払い、各人10％引き（3000円−300円＝2700円）。2 ✗ 割引前の1人分。3 ✗ 割引後の3人分合計。4 ✗ カード払い（割引無効）の3人分合計。 |
| 5番 | 3 | 課長「パンフレットが入った封筒を各机に置いて準備は完了となります」→今日この後の作業。机といすは「準備が整い」、パソコンは「設置は当日行います」、来場者の案内は「当日は」。 |

## 問題2
| 番号 | 正解 | 解説 |
|---|---|---|
| 1番 | 3 | 1 ✗「この店はもともとパン作りが好きな母がやる予定だった」が、母は病気になり「卒業する前に母は亡くなりました」→一緒にやる話ではない／2 ✗「『やってくれ』と言われたわけじゃないんですが」と明確に否定／3 ○「母はずっとパン屋をやりたかったので店を諦めることをとても残念がっていた」「僕が何とか形にしたいと思いました」→母の夢をかなえたかった／4 ✗「母のレベルにはまだまだ」で、味を残す話はしていない。 |
| 2番 | 3 | 女「もっと宣伝に力を入れたらどうですか？」→男「そうだね、やってみよう」＝ホームページを作る。値下げは「原材料の価格が上がってて厳しい」、早朝開店は「アルバイトを見つけるのが難しい」、チラシの割引券は「売り上げが伸びなかった」。 |
| 3番 | 3 | 「私は紐状に細く切ってクッションのカバーや花瓶の下に敷くものを編むのに使っています」→あみものの材料として使う。ゆずる・作り変える・リサイクルショップは他の人の例。 |
| 4番 | 2 | 「肉体的なことよりも気持ちの面で限界を感じまして」とあり、精神的な限界が引退の理由。1 ✗「肉体的」→「肉体的なことよりも」と否定。3 ✗「指導者」→引退後の進路。4 ✗「メダル」→司会者の推測に対し、怪我の恐怖など気持ちの限界を主因としている。 |
| 5番 | 2 | アナウンサー「私もまさかこの箱に花が入っているとは思いませんでした」→箱に入っているのは花。お菓子と宝石は「お菓子が入っていそうな箱や、宝石箱のようなものもあります」と見た目の話にすぎず、コーヒーは「箱にはコーヒーが入っていると思われる方も多いそうです」という客の思い込み。 |
| 6番 | 2 | 「健康診断で筋肉を増やしたほうがいいって言われた」が理由。1 ✗「ダイエット？」→女の人の推測で、男の人は「というか」と否定して言い直している。3 ✗「景色も楽しめる」→始めた後に挙げた利点。4 ✗「裏道のカフェにも寄れる」→同じく付け足しの利点。 |
